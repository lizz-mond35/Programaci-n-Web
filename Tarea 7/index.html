Resumen HTML: principales conceptos y etiquetas

Esta página va a resumir los principales conceptos y etiquetas vistas en la clase de programación web 1, en el módulo HTML

Conceptos principales HTML

HTML

¿Qué es HTML?, el lenguaje de marcado de hipertexto es un lenguaje de marcas que se utiliza para estructurar sitios web.

Elemento HTML

Un elemneto HTML es la unidad básica de estructura y contenido de una página web, y esta compuestra de:

  1. Etiqueta de apertura
  2. Pares atributos-valor
  3. Contenido
  4. Etiqueta de cierre

Etiqueta <head>

Es una etiqueta que se uitliza para comunicarse con el navegador a través de los metadatos, permite mejorar el SEO, además se enlazan archivos externos de estilos o scripts.

Etiqueta <body>

Dentro de esta etiqueta va todo el contenido que ve el usuario en nuestra página web.

Contenedores semánticos

<Header> Es una etiqueta utilizada para el contenido introductorio de una página web, puede contener el logo, el menú de navegación principal, el nombre de la empresa, etc.
<Nav> Etiqueta utilizada para el menú de navegación principal, suele contener enlaces a otras páginas relacionadas o navegar por la página principal, no debe de haber más de un contenedor nav en la página.
<Main> Etiqueta única de una página web, cuyo propósito es resaltar nuestro objetivo o mensaje principal del sitio web, dentro se colocará el contenido principal de nuestra página.
<Section> Etiqueta que poco a poco se intenta que sustituya a <Div> , su uso es para dividir a una página web en secciones y agrupar contenido relacionado.
<Article> Etiqueta que se utiliza para agrupar contenido autónomo, que si se separa de otro contenido sigue teniendo coherencia, normalmente se compone de un encabezado y contenido.
<Footer> Etiqueta que normalmente se encuentra hasta el final de una página y funciona como cierre del sitio web, a menudo contiene datos de contacto, derechos de autor u otra información complementaria.
<Aside> Etiqueta que representa una sección de la página web cuyo contenido no está directamente relacionado con el contenido principal del documento, como: barras laterales, publicidad, enlaces a otros artículos relacionados, etc.

Elementos principales de HTML

Elemento <a>

Este elemento contiene enlaces para navegar a otras páginas:

  • Externos
  • Internos
  • Anclaje

Algunos valores especiales que tiene en su atributo href son:

Href= "https://wa.me/5569842536"
Este valor envía un WhatsApp a un número determinado.
Href= "mailto:example@gmail.com"
Este valor envía un correo a un email específico.

Elemento <form>

Es la manera en que los usuarios se pueden comunicar con una página web, gracias a este elemnto se pueden procesar datos de los usuarios segun el objetivo de nuestra página web
